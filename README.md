## 📋 О проекте

**Vector Safety Filter** — это прототип интеллектуальной системы, способной в реальном времени анализировать векторные рисунки пользователей и классифицировать их по признаку безопасности для детской аудитории.

Система работает непосредственно с **векторными данными** (последовательностями координат штрихов), а не с растровыми изображениями, что позволяет:
- 🚀 Анализировать рисунки в реальном времени без потери качества
-  Хранить данные в сжатом формате (до 97% экономии пространства)
- 🎯 Распознавать геометрические паттерны запрещённой символики

### Что умеет система

- ✅ **Собирать** векторные рисунки с ручной разметкой (safe/unsafe)
- 📊 **Анализировать** датасет с визуализацией статистики
-  **Аугментировать** данные (7 видов трансформаций)
- 🧠 **Обучать** гибридную CNN + LSTM нейронную сеть
- 🔍 **Классифицировать** новые рисунки в реальном времени
- 📈 **Визуализировать** метрики качества и ошибки

## 🚀 Быстрый старт

### 1. Установка зависимостей

```bash
# Клонируйте репозиторий
git clone https://github.com/AstroPolly/vector-safety-filter.git
cd vector-safety-filter

# Создайте виртуальное окружение
python -m venv .venv

# Активируйте (Windows PowerShell)
.venv\Scripts\Activate.ps1

# Установите зависимости
pip install -r requirements.txt

###2. Сбор данных
Запустите модуль сбора данных:
python collector_app.py
Рисуйте на холсте, выбирайте категорию (✅ Безопасно / ⛔ Опасно) сохраняйте в базу данных.

###3. Обучение модели
jupyter notebook learn.ipynb
Откройте Jupyter Notebook:
Выполняйте ячейки по порядку:
Загрузка данных из БД
Визуализация датасета
Аугментация данных
Обучение модели (50 эпох)
Анализ метрик и ошибок
После обучения модель сохранится в best_model.pth.

###4. Проверка рисунков
Запустите приложение инференса:
python inference_app.py
Нарисуйте что-нибудь и нажмите «🔍 ПРОВЕРИТЬ БЕЗОПАСНОСТЬ».
🧠 Архитектура нейронной сети
Модель использует гибридную архитектуру CNN + LSTM:
Вход: [batch, 20 штрихов, 50 точек, 2 координаты]
  │
  ├─ CNN (извлечение признаков из штрихов)
  │   ├─ Conv1d(2→32) + ReLU + MaxPool
  │   └─ Conv1d(32→64) + ReLU + MaxPool
  │
  ├─ LSTM (анализ последовательности штрихов)
  │   └─ 2 слоя, hidden_size=64
  │
  └─ Классификатор
      ├─ Linear(64→32) + ReLU + Dropout
      └─ Linear(32→1) + Sigmoid
      
Выход: вероятность unsafe ∈ [0, 1]

###Аугментация данных

Для борьбы с переобучением реализовано 7 видов аугментации:
🔄 Поворот на 90°, 180°, 270° (30%)
↔️ Отражение по горизонтали (25%)
↕️ Отражение по вертикали (25%)
Добавление шума (40%)
✂️ Удаление штрихов (20%)
🗑️ Удаление точек (30%)
Масштабирование 0.7–1.3 (20%)
